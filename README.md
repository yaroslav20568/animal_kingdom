# Animal Kingdom

## Русский

### О проекте

Animal Kingdom — это интерактивное Flutter-приложение в виде книги о животных. Пользователи могут открыть книгу и листать страницы с информацией о различных животных.

### Что было сделано

- Реализован экран старта с закрытой книгой
- Добавлена анимация открытия книги
- Создан экран книги с навигацией между страницами
- Реализован репозиторий с данными о 16 животных
- Добавлена модель данных Animal с информацией о животных (название, описание, среда обитания, рацион, продолжительность жизни, категория)
- Реализованы виджеты для отображения страниц книги с информацией о животных
- Добавлена тактильная обратная связь при взаимодействии
- Реализован индикатор текущей страницы
- Добавлена поддержка планшетов с адаптивным дизайном

### Используемые пакеты

- `flutter` — основной SDK Flutter
- `cupertino_icons: ^1.0.8` — иконки в стиле iOS
- `flutter_lints: ^6.0.0` — линтер для Dart/Flutter (dev)
- `flutter_launcher_icons: ^0.13.1` — генерация иконок приложения (dev)

## English

### About the Project

Animal Kingdom is an interactive Flutter application designed as a book about animals. Users can open the book and browse through pages with information about various animals.

### What Was Done

- Implemented a start screen with a closed book
- Added book opening animation
- Created a book screen with page navigation
- Implemented a repository with data about 16 animals
- Added Animal data model with information about animals (name, description, habitat, diet, lifespan, category)
- Implemented widgets for displaying book pages with animal information
- Added haptic feedback for user interactions
- Implemented current page indicator
- Added tablet support with adaptive design

### Used Packages

- `flutter` — Flutter core SDK
- `cupertino_icons: ^1.0.8` — iOS-style icons
- `flutter_lints: ^6.0.0` — Dart/Flutter linter (dev)
- `flutter_launcher_icons: ^0.13.1` — app icon generator (dev)
